# Poker Theory Final

This cumulative final checks the full poker-theory course. It combines calculation, conceptual strategy, and scenario recognition.

Use the same habits you built throughout the course: identify the relevant pot, define the range interaction, choose the formula, and then interpret the result strategically.

Correctness and explanations are held until the results screen, so this page intentionally contains no answer key.

## Scope

- Probability, outs, pot odds, and expected value
- Range advantage, blockers, nut advantage, and GTO foundations
- Minimum Defense Frequency, alpha, and balanced bluffing
- Bet sizing, geometric sizing, board texture, position, and initiative
- Multi-street planning, implied odds, and tournament ICM pressure
