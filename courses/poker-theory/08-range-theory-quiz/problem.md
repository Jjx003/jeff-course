# Range Theory Quiz

You've learned to think in distributions rather than single hands. Now drill the mechanics: combo counting, blocker arithmetic, and recognising which player holds range or nut advantage in a given spot.

Each attempt randomises the numeric questions, so the numbers will differ each time you retake. Use these questions to build fast, automatic recall — in live play you won't have a calculator.

**Topics covered:**

- Pocket-pair and suited-hand combo counts
- Blocker effects on combo frequency
- Range advantage on dry vs. wet boards
- Polarised vs. capped range identification
- Range-percentage to combo-count conversion

Aim for 80%+ before moving on to Module 09. If a combo-counting question trips you up, revisit the Theory tab in Module 07 for the formal derivations.
