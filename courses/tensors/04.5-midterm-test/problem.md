# Midterm Test: Tensor Foundations

This test checks the first half of the tensor track: raw tensor layout, shape and stride reasoning, matrix multiplication, broadcasting, element-wise operations, and activation functions.

Work from the definitions and implementation patterns you have practiced so far. Some questions ask for exact numeric results, so keep track of axis order, final shapes, and whether an operation creates a view or a new allocation.

You will see correctness and explanations only after submitting the test.
