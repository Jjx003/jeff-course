# Triage card: hypersensitivity

For every reaction, write **time from exposure**, **recognition molecule**, **effector
cell or pathway**, **injury mechanism**, and **best confirming evidence**.

- In anaphylaxis, treat airway and circulation with intramuscular epinephrine first.
- A positive IgE test means sensitization until exposure history supports allergy.
- Type II antibodies can destroy, activate, or block; name the function.
- For Type III, explain why complexes persist and where they deposit.
- For Type IV, identify the responding T-cell program and account for the delay.
- A biologic response identifies a useful node, not necessarily the original cause.

Common trap: "hygiene hypothesis" is not a mechanism. Specify exposure, developmental
window, barrier or microbial pathway, comparator, and measured allergic outcome.
