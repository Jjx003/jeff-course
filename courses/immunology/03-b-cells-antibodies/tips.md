# Study guide

## Retrieval prompts

- Which process creates a receptor before antigen exposure?
- Which process changes constant region but preserves the assembled variable region?
- How can two antibodies share $K_D$ yet differ in behavior?
- Why can the highest-affinity candidate fail neutralization?

## Keep a mechanism ledger

For every antibody claim, name the **epitope**, **binding measurement**,
**isotype/Fc context**, **tissue**, and **functional assay**. Missing fields are
often where an overclaim hides.

## Common traps

- Somatic hypermutation is not class switching.
- Follicular dendritic cells are not conventional peptide-presenting dendritic cells.
- Mutation count is not a synonym for affinity.
- Serum antibody titer does not directly count memory B cells.

## Quantitative check

Calculate occupancy for $K_D=1$, 10, and 100 nM at ligand concentrations of 1,
10, and 100 nM. Then explain why this nine-cell table still cannot predict
neutralization without epitope and assay information.
