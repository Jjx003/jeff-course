# Study guide

## Retrieval prompts

- Why are long-lived plasma cells and memory B cells not redundant?
- What is the performance test in germinal-center selection?
- Why can blood underestimate both protective and pathogenic memory?
- What does contraction accomplish?

## Build a six-row timeline

From day 0 through recall, sketch antigen, innate cytokines, effector cells,
germinal-center activity, antibody, and memory. Do not make every curve peak on
day 7. Label which assay could measure each row.

## Common traps

- Waning serum antibody does not mean all memory vanished.
- A larger secondary response does not prove sterilizing protection.
- Detecting a "resident-memory marker" in one biopsy does not prove residence.
- Contraction is not simply immune exhaustion.

## Extend the booster dataset

Propose one tissue measurement and one lineage measurement that would answer
questions the blood table cannot. State what result would support local memory
and what result would support recruitment of previously unseen clones.
