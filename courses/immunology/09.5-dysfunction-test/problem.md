# Regulation and dysfunction cumulative test

Symptoms are rarely mechanism labels. Build a causal account from the evidence:

Keep the course coordinates visible:

| Coordinate | Dysfunction question |
|---|---|
| recognition | is the target self, harmless foreign material, or a pathogen? |
| context | which inflammatory, regulatory, or treatment signal changes the response? |
| compartment | where is the effector missing, trapped, or causing injury? |
| time | is this sensitization, acute injury, chronic feedback, or loss of function? |
| control | which functional assay or perturbation distinguishes the nearest rival? |

| Evidence | Mechanistic question |
|---|---|
| Timing: minutes, weeks, or years | Which effector can act on that timescale? |
| Counts versus function | Is a population absent, misplaced, or ineffective? |
| Deposits, complement, or tissue pattern | Where is injury being generated? |
| Treatment time course | Which cells or mediators were removed, and which persisted? |

For each vignette, identify the initiating signal, dominant effector, target
compartment, feedback loop, and the control that separates the leading
explanation from its nearest rival.
