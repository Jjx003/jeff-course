# Deck: The Transformer

Fifty cards on the architecture. These are the questions a rapid-fire technical discussion opens with, and the ones you will be quietly graded on for the rest of the conversation.

Several cards ask for a **number** — parameters per layer, KV cache bytes per token, the SwiGLU hidden size. Those are the ones worth the most. Anyone can say "GQA reduces the KV cache". Being able to say "8x, so 0.5 GB per sequence at 4k instead of 2.1 GB, which is what makes batch 64 fit" is a different answer to a different candidate.

Work through it once, then let the [Review](/review) queue handle it.
