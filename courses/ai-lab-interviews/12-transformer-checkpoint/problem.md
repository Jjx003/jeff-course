# Checkpoint: The Transformer

Twenty-one questions covering modules 6 through 11. Feedback is immediate, so treat a wrong answer as a pointer back to the relevant reading rather than as a score.

Several questions are written the way an interviewer would ask them — the plausible-sounding distractor is the answer someone gives when they have read a summary rather than an implementation. If a question feels like it has two right answers, the difference between them is usually the point.
