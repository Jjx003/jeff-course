# Database Implementation Final

This final test spans the full database implementation track. It asks you to connect decisions from low-level C++ ownership and storage layout all the way up to query planning:

- Storage-engine resource management, slotted pages, disk I/O, and buffer-pool behavior
- B+ tree and extendible hash index tradeoffs
- Tuple/schema layout and typed values
- Volcano execution, sequential scans, joins, and pipeline breakers
- Predicate pushdown, cardinality estimation, and physical planning
- The end-to-end SQL lifecycle from parsing to execution

The test includes conceptual questions and calculation-style questions. Correctness and explanations are intentionally withheld until the results screen, so answer from your own model of the system rather than from hints in this page.

After submitting, use the review screen to identify which layer of the database stack needs another pass.
