# Database Implementation Midterm

This test covers the first half of the database implementation track:

- RAII, smart pointers, move semantics, templates, and memory resources
- Slotted pages, page-aligned disk I/O, and stable record identifiers
- Buffer pool pinning, dirty pages, eviction, and page tables
- B+ tree search, splitting, separator keys, and range-scan structure

Use the questions to check whether the storage-engine pieces fit together in your head. Some questions ask for small calculations, so keep the formulas from the earlier modules handy. Correctness and explanations are shown only after you submit the test.

When you finish, review any missed questions before continuing to hash indexes and query execution.
