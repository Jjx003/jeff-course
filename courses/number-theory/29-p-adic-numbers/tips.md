### Going Deeper
- **Ostrowski's Theorem:** This fundamental theorem states that every non-trivial norm on $\mathbb{Q}$ is equivalent to either the standard absolute value or a $p$-adic norm for some prime $p$.
- **Hasse Principle:** The "Local-to-Global" principle. It asks whether a polynomial equation has a solution in $\mathbb{Q}$ if and only if it has solutions in $\mathbb{R}$ and all $\mathbb{Q}_p$. It holds for quadratic forms (Hasse-Minkowski Theorem) but fails for higher degrees.
- **Visualizing $\mathbb{Q}_p$:** Since $|x-y|_p$ only takes values in $\{p^k\}$, the topology of $\mathbb{Q}_p$ is a **Cantor set**. It is totally disconnected.
